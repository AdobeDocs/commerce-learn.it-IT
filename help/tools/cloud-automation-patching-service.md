# Automazione dell&#39;applicazione di patch Adobe Commerce

Adobe Commerce Patching Automation è una funzione all&#39;interno di Adobe Commerce Site Wide Analysis Tool (SWAT) che semplifica il processo di individuazione e applicazione delle patch di sicurezza. Gli utenti accedono all’automazione dell’applicazione di patch tramite l’amministratore Commerce nel dashboard SWAT, selezionano il progetto e l’ambiente e visualizzano le patch disponibili.
