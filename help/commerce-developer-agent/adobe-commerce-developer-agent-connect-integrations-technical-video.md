# Integrazioni di connessione di Adobe Commerce Developer Agent

Il codice generato richiede un luogo in cui eseguire e una connessione al tuo archivio. Questa fase integra tutto, ospitando il codice in App Builder, connettendolo all’istanza Adobe Commerce e collegando un archivio GitHub, prima che la funzione sia abilitata.

## A chi serve questo video?

* Sviluppatori Commerce
* Architetti di soluzioni
* Ingegneri back-end

## Contenuto video

* Creazione di un progetto App Builder e di un’area di lavoro per ospitare il codice creato dall’agente sviluppatore
* Guardando l’agente impalcare il progetto e individuare gli elementi di configurazione in sospeso
* Aggiunta delle credenziali API Adobe Commerce as a Cloud Service richieste nella console per sviluppatori
* Connessione del codice a una specifica istanza di Adobe Commerce Cloud Service
* Per archiviare e modificare la versione del codice, collega un archivio GitHub
