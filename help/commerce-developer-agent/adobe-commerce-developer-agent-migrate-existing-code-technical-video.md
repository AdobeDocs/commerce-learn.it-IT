# Adobe Commerce Developer Agent: migrazione del codice esistente

Non tutti i progetti iniziano da una configurazione vuota. Questo esempio migra un’estensione esistente ad App Builder, passando dalla piattaforma PaaS ad Adobe Commerce as a Cloud Service, utilizzando lo strumento di valutazione della migrazione per alimentare Developer Agent.

## A chi serve questo video?

* Sviluppatori Commerce
* Architetti di soluzioni
* Ingegneri back-end

## Contenuto video

* Scansione di un&#39;istanza Commerce esistente con lo strumento di valutazione della migrazione: valutazioni della complessità, impatto per modulo, segnali di rischio e raccomandazione di ricostruzione, refactoring, sostituzione o rimozione
* Revisione della valutazione di un modulo ad alto impatto, inclusi hook, file e un riepilogo delle finalità in linguaggio semplice che funge anche da prompt predefinito
* Invio della valutazione direttamente all’agente sviluppatore senza copia manuale
* Per concentrare il primo passaggio su funzionalità specifiche, rispondere alle domande dell&#39;agente relative all&#39;ambito
* Generazione di un blueprint di webhook sincroni che sostituiscono la logica legacy più rischiosa con un diagramma dell’architettura
* Creazione dell’implementazione con un file di test corrispondente scritto accanto a ciascun gestore
